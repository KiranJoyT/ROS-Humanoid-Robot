# ROS Humanoid Robot

A ROS-based humanoid robot modeling and visualization project using URDF, RViz, and MoveIt configuration.

## Project Overview

This project explores the modeling and simulation of a humanoid robot in ROS. The robot model was loaded and visualized in RViz, providing a 3D representation of its links, joints, and coordinate frames.

## Features

- Humanoid robot model using URDF, if included in the source package
- 3D robot visualization in RViz
- Robot link and joint representation
- MoveIt configuration, if included in the project
- RViz configuration for viewing the robot model

## Technologies

- ROS 2 
- URDF 
- RViz
- MoveIt 

## Repository Structure

The humanoid_robot/ directory contains the ROS package and its available model, launch, visualization, and configuration files.
